1-mohamed Backups

This service helps the project operator recover the 1-mohamed transport ledger after data loss. It stores verified recovery copies in a private folder in the operator’s Google Drive.

The operator can select a recovery file and an Excel workbook with business data only, or an encrypted database copy that requires a separate decryption key. Recovery is tested in a separate database.

Only the backup operator needs to connect Google Drive. Ledger users use the project’s own sign-in and do not connect their Google accounts to the backup service.
