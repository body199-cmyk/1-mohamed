1-mohamed Backups

This service helps the project operator recover the 1-mohamed transport ledger after data loss. It encrypts a copy of the database before storing it in a private folder in the operator’s Google Drive.

The backup process retrieves and checks the encrypted copies. The operator holds the decryption key separately and can restore a copy to a separate database for verification.

Only the backup operator needs to connect Google Drive. Ledger users use the project’s own sign-in and do not connect their Google accounts to the backup service.
