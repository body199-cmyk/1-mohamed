## ١. التدفق العام ومسارا الإدخال (معتمد A13-R1)

النظام يوفر مسارين لتسجيل النقلات:

```
                  ┌───────────────────────────────┐
                  │      شاشة تسجيل النقلات       │
                  └──────────────┬────────────────┘
                                 │
         ┌───────────────────────┴───────────────────────┐
         ▼                                               ▼
┌─────────────────────────────┐        ┌─────────────────────────────┐
│  المسار الأول (الأساسي):    │        │  المسار الثاني (اختياري):   │
│  تسجيل نقلة مباشرة فورًا   │        │  استخدام بيانات مشتركة      │
│  (كل البيانات في النقلة)    │        │  (تسهيل إدخال للنقلات)      │
└──────────────┬──────────────┘        └──────────────┬──────────────┘
               │                                      │
               │ «حفظ النقلة»                         │ «ابدأ تسجيل النقلات»
               ▼                                      ▼
┌─────────────────────────────┐        ┌─────────────────────────────┐
│ نقلة جديدة / حفظ مستقل      │        │ نقلة جديدة بنسخة قابلة      │
│ لكل نقلة                    │        │ للتعديل بالكامل             │
└─────────────────────────────┘        └─────────────────────────────┘
```

- **بيانات شغل اليوم اختيارية تمامًا:** المستخدم يستطيع تسجيل النقلة مباشرة دون المرور بخطوة البيانات المشتركة. تجهيز بيانات اليوم ليس شرطًا لفتح نموذج النقلة أو حفظه، وعدم استخدامها ليس خطأً ولا حالة ناقصة.
- **التسجيل المباشر:** يتيح إدخال التاريخ، العربية، المقاول الآخر، اتجاه الشغل، من وإلى للطريق، عدد الأطنان، سعري المقاول والعربية («نفس السعر» افتراضيًا)، خانة مصاريف واحدة، ورقم إيصال وملاحظات اختياريين.
- **استخدام البيانات المشتركة:** وسيلة اختيارية لتسهيل الإدخال وتعبئة القيم المتكررة للنقلات التالية. ليست حركة مالية ولا تحفظ شغلًا. كل نقلة تأخذ نسخة مستقلة قابلة للتعديل. تعديل النقلة لا يغير المشترك، وتغيير المشترك يؤثر على النقلات الجديدة اللاحقة فقط.
- **حماية المدخلات:** عند الانتقال بين التسجيل المباشر واستخدام البيانات المشتركة، لا تُستبدل مدخلات مسودة قائمة بصمت.
- **لا توريث ولا قوالب دائمة:** عند بدء يوم جديد لا تُورث بيانات اليوم السابق تلقائيًا. لا توجد قوالب دائمة تُحفظ بين الجلسات.

### اتجاه الشغل والمسؤول عن حساب العربية (وفق A02 وA04)

«من / إلى» للطريق فقط. اتجاه الشغل اختيار صريح وواضح في النقلة:
- أحمد جاب العربيات لشغل [اسم المقاول].
- [اسم المقاول] جاب العربيات لشغل أحمد.

اختيار المقاول الآخر واتجاه الشغل مطلوبان قبل حفظ النقلة. لا يُستنتج الاتجاه من الطريق أو ملكية العربية. تظهر عبارة مشتقة للقراءة: «المسؤول عن حساب العربية: أحمد / [اسم المقاول]» حسب الاتجاه. كما يوضح لصالح من تكون قيمة الشغل (تبادل عمل).

## ٤. البحث عن عربية مسجلة وإضافة عربية جديدة

### ٤.١ البحث عن عربية مسجلة

- المستخدم يكتب جزءًا من رقم اللوحة أو الرقم وتتفلتر النتائج لحظيًا.
- رقم العربية هو الأهم في البحث؛ اسم العربية أو السائق مساعد فقط.
- الضغط على العربية يحددها ويعود للنموذج مباشرة دون فقد بقية المدخلات.
- اختيار العربية لا يفرض وزنًا أو سعرًا مسبقًا؛ الأطنان تُدخل لكل نقلة.

### ٤.٢ إضافة عربية جديدة (نافذة سريعة)

- نافذة منبثقة بسيطة (Dialog / Bottom Sheet) فوق النموذج.
- الحقول: رقم العربية (إلزامي)، اسم السائق (اختياري).
- بعد الحفظ: يتم اختيار العربية تلقائيًا وتُغلق النافذة وتظل **جميع مدخلات النقلة كما هي دون فقد**.
- نفس الآلية تُطبّق لاختيار وإضافة المقاولين.

## ٥. الحقول المشتركة والخاصة ومراجعة النقلة

### ٥.١ جدول الحقول وقواعدها

| الحقل | في التسجيل المباشر | مع استخدام البيانات المشتركة | ملاحظات التحقق |
|---|:---:|:---:|---|
| تاريخ الشغل | مطلوب | ينسخ وقابل للتعديل | لا ينتقل تلقائيًا من الأمس |
| رقم العربية | مطلوب | خاص بكل نقلة | اختيار العربية لا يثبت سعرًا أو وزنًا |
| الأطنان | مطلوب | خاص بكل نقلة | مطلوب دائمًا، لا يُخمن ولا يُنسخ |
| المقاول الآخر | مطلوب | ينسخ وقابل للتعديل | بحث / اختيار / إضافة سريعة |
| اتجاه الشغل | مطلوب | ينسخ وقابل للتعديل | أحمد أحضر لـ K أو K أحضر لأحمد |
| المسؤول عن الحساب | مشتق للعرض | مشتق للعرض | يعتمد حصرًا على اتجاه الشغل |
| الطريق (من / إلى) | حقول نصية | تنسخ وقابلة للتعديل | تصف الطريق فقط ولا تحدد الاتجاه |
| سعر طن المقاول | مطلوب | ينسخ وقابل للتعديل | حتى منزلتين عشريتين (D01) |
| ربط «نفس السعر» | مفعّل افتراضيًا | ينسخ وقابل للتعديل | ربط وفصل مستقل لكل نقلة (D14) |
| سعر طن العربية | مفعل عند فصل الربط | ينسخ وقابل للتعديل | مستقل عند فصل الربط |
| مصاريف النقلة | خانة واحدة (افتراضي ٠) | تنسخ وقابلة للتعديل | تشمل الكارتات والمسترد للعربية (D05) |
| رقم الإيصال | اختياري | خاص بالنقلة | نص للحفاظ على الأصفار والحروف (D09) |
| ملاحظات | اختياري | خاص بالنقلة | نص اختياري (D09) |

### ٥.٢ مراجعة النقلة قبل الحفظ

يعرض قسم المراجعة بوضوح:
1. **إجمالي أطنان النقلة:** معروض بوحدته ودقته العددية.
2. **إجمالي قيمة الشغل للمقاول:** مع بيان صريح لصالح من (أحمد أو المقاول الآخر).
3. **إجمالي مستحق العربية:** شامل مصاريفها المستردة، مع توضيح عند أي مقاول يكون الالتزام.

> **ضوابط وتنبيهات مالية وإجرائية:**
> - لا يُجمع مبلغا قيمة الشغل ومستحق العربية معًا؛ فهما وصفان مختلفان لنفس النشاط، وليس إيرادين مستقلين.
> - عند تساوي السعرين يتطابق المبلغان؛ وفصل ربط السعرين (D14) يسمح باختلافهما لكنه **لا يفرض اختلاف القيم**، وتعرض القيم الفعلية المحسوبة دائمًا.
> - **المصدر الوحيد للمعادلات وأمثلة الحساب التفصيلية:** هو [ACCOUNTING_RULES](ACCOUNTING_RULES.md)؛ لا نكرر صياغة المعادلات أو أمثلة الحساب التفصيلية هنا منعًا للازدواج. الأرقام الواردة في المخططات النصية هي رسوم توضيحية فقط.
> - **اكتمال المدخلات:** لا يظهر مبلغ صالح ما دامت الأطنان أو الأسعار أو بقية المدخلات الحسابية اللازمة ناقصة، بل تظهر عبارة: «أدخل البيانات لحساب الإجمالي».
> - **حماية المسودة:** الرجوع أو بدء نقلة جديدة لا يمسح مسودة معدلة بصمت، بل يبقيها أو يطلب تأكيد تركها من المستخدم.
> - **منع التكرار ومعرف الطلب:** أثناء الحفظ يُعطل الزر منعًا للتكرار؛ وعند انقطاع الرد أو إعادة المحاولة، تُستخدم نفس بيانات الطلب بنفس المعرف حصرًا؛ ولا يُستخدم نفس المعرف لمحتوى مختلف (رفض التعارض وفق W05).

## ٨. تقرير إنجاز المهمة (محدث بعد إصلاحات UI-03-FIX-01)

### ما تم إنجازه
1. **تحديث مساري الإدخال:** جعل بيانات شغل اليوم خيارًا مساعدًا غير إلزامي، وتوثيق التسجيل المباشر كمسار أساسي مستقل لحفظ النقلة دون إعداد مسبق.
2. **دمج المصاريف والكارتات:** إلغاء حقل الكارتات المنفصل واعتماد خانة واحدة باسم «مصاريف النقلة» مع نص المساعدة المعتمد «تشمل الكارتات وغيرها من المصاريف المستردة للعربية»، ومنع الازدواج المالي.
3. **تحديث الرسوم النصية والجداول:** تصحيح مخطط شاشة بيانات اليوم المشتركة ومخطط شاشة تسجيل النقلة وجداول الحقول لعكس الخانة الواحدة والمسارين.
4. **ضبط قسم مراجعة النقلة (UI-03-FIX-01):** إزالة تكرار أمثلة الحساب والمعادلات التفصيلية والإحالة إلى ACCOUNTING_RULES كمصدر وحيد، وتأكيد أن فصل السعرين لا يفرض اختلاف القيم، ومنع عرض إجمالي صالح عند نقص المدخلات، وتأكيد حماية المسودة ومنع تكرار الطلب وفق W05.
5. **حماية المدخلات واستقلال النقلات:** توثيق عدم فقد المسودات عند التبديل أو الرجوع، وعدم توريث قيم اليوم السابق، وعدم فرض أوزان أو أسعار على العربية.
