## نقطة الاستئناف الدقيقة

**المهمة الواحدة الجارية:** [AUTH-01/PREP / H039](AUTH_01_H039_REVIEW.md).
اقرأ [AGENTS](../AGENTS.md) ثم [SUBTASKS](SUBTASKS.md) ثم التقرير. راجع `apps/web/src/proxy.ts` و`apps/web/src/app/login/page.tsx` واختبار `tools/auth-boundary-smoke.mjs` وتعديل GitHub Actions (١٢ GET ممنوعًا و٦ POST ممنوعًا، مع فحص الصفحات والأصول العامة). شغّل اختبارات الحزم وSQL والبناء وسيناريو HTTP على أحدث Commit؛ أعد مرور مراجعة نقدية مستقلًا، وسجّل عيوبًا واختبارات منع العودة قبل دمج فرع H039.

**العائق الحقيقي التالي بعد H039:** تركيب حزم Supabase بنسخ مقفلة، وتأمين مشروع اختبار مستقل لإثبات دخول المالك وغير المالك والجلسات واسترجاع كلمة المرور وحماية RPC/HTTP. ما بُني في H039 **ليس تسجيل دخول**، والمسارات الدائمة تظل معطلة.

القرارات D15 وD16 **ما زالت مفتوحة للدفعات**؛ لا تغيّرها أو تعطل العمل المستقل بسببها.
