1. راجع [تقرير H038](DB_03_H038_REVIEW.md)، وتأكد من نجاح CI على **أحدث commit** في PR #1 (بما فيه جناح `05_phase_c_adversarial_review.sql`): `npm ci`، `npm run check`، `npm run db:verify`، أدوات التحكم السلبي الثلاث، `npm run build`.
2. نتائج التشغيل الأولى ناجحة؛ راجع الفروقات والعقد والتوثيق وكرّر CI بعد كل تغيير. لا تنقل حالة المهمة إلى مكتملة إلا بعد تحقق حديث ومراجعة فعلية.
3. بعد قبول DB-03 تقنيًا ودمج PR بإذن المستخدم، المهمة التالية `AUTH-01` في بيئة اختبار منفصلة، أو مراجعة `DB-04-PAYMENTS` بعد حسم D15/D16 عند الحاجة. لا تنفيذ تلقائي لمرحلة أخرى.

**القرارات المالية المفتوحة:** D15 وD16 تخصان الدفعات فقط؛ لا تغيّر فيهما. تحويل الافتتاحيات D04 وتفاصيل النسخ D07 في مراحلها اللاحقة.
