## 5. مراجعة العقد المالي والقواعد المعمارية

1. **إشارة الرصيد والمستفيد:**
   - الموجب (+) يعني رصيدًا لصالح أحمد (`beneficiary: "AHMED"`).
   - السالب (-) يعني رصيدًا لصالح الطرف الآخر (`beneficiary: "COUNTERPARTY"`).
   - الصفر (0) يعني تعادل الحساب (`beneficiary: "BALANCED"`).
2. **الرصيد السابق (`openingBalancePiastres`):**
   - يشمل الرصيد الافتتاحي (`opening.signedPiastres`) بالإضافة إلى تراكم الحركات السابقة لتاريخ بداية الفترة (`workDate < period.from`)؛ ولا تتسرب قيم حركات ما قبل الفترة إلى إجماليات شغل الفترة الحالية.
3. **شمولية حدود الفترة:**
   - بداية الفترة (`period.from`) ونهايتها (`period.to`) شاملتان؛ الحركات التي تقع في هذين اليومين تدخل بالكامل في صفوف وإجماليات الكشف.
4. **مبالغ النقلات الداخلة:**
   - تدخل مقربة مسبقًا لكل نقلة (`contractorTotalPiastres` كـ `bigint` بالقروش)؛ ولا يجري المحرك أي عمليات تقريب للأوزان أو الأسعار.
5. **عزل كشف المقاول عن دفعات العربيات:**
   - كشف المقاول يخص حصرًا فرق شغل النقلات بين المقاولين؛ ولا يتضمن أي دفعات أو تعاملات نقدية للعربيات.
6. **التحقق الشامل وعدم التجزئة:**
   - يتم التحقق من صحة كامل كائن المدخلات والحركات قبل إجراء أي حساب أو تجميع؛ ولا ينتج أي تجميع جزئي عند وجود أي خطأ، ولا يتم تعديل أو تشويه المدخلات الأصلية.
7. **إدارة المعرفات:**
   - تكرار معرف الحركة (`id`) يُرفض بالخطأ `DUPLICATE_MOVEMENT_ID`.
   - تشابه تاريخ ومبلغ نقلتين بمعرفين مختلفين يُحسب كنقلتين مستقلتين كاملتين.

## 6. ما لم يُختبر / حدود الدمج والربط

1. **كود تطبيق أو واجهة مستخدم أو قاعدة بيانات:** لم يُنشأ أي كود لـ Next.js أو React أو Supabase؛ العمل مقتصر على حزمة كشف شغل المقاول المستقلة.
2. **الدفعات النقدية:** الحزمة مخصصة لكشف فرق الشغل بين الطرفين، ولا تتعامل مع تسجيل أو تسوية الدفعات النقدية المعلقة بـ T08.
3. **القرارات المفتوحة (D15 و D16):**
   - القراران ما زالا مقترحين مفتوحين بانتظار قرار المستخدم دون اعتماد ضمني.
   - فرز حركات اليوم نفسه في الكشف يتم برمجياً لأغراض العرض الحتمي (`deterministic display`) فقط عبر مقارنة `workDate` ثم `id`، وليس ترتيبًا زمنيًا حقيقيًا لحركات اليوم.
4. **اشتراط اللقطة المكتملة:** هذه الحزمة تفترض استلام لقطة كاملة من الحركات الفعالة؛ ولا تدعم التصفح الجزئي المباشر من قاعدة البيانات.
