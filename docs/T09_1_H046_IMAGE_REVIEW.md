# H046 — T09.1: صورة PNG من كشف المقاول

## المصدر والنطاق
- المصدر الوحيد `toStatementDocument` الذي يغذي HTML/CSV. لا تعديل محركات الحساب أو قاعدة البيانات، ولا تقريب جديد ولا إحصاءات بديلة.
- Canvas Arabic RTL بحجم ثابت للعرض وطول يتناسب مع صفوف كشف الفترة؛ يتضمن المقاول/الفترة/تاريخ الإنشاء/قيم الملخص الستة والتفاصيل كاملة حتى حد canvas الآمن.
- عند تجاوز حد الصورة الواحدة، تظهر رسالة عربية تطلب تقليل الفترة أو استخدام CSV/الطباعة، ولا يسقط النظام أي حركة بصمت. طباعة PDF الموجودة من قبل لا تعني إنشاء PDF مستقل.

## مراجعة نقدية ومخاطر يجب فحصها
- **اتساق الأموال:** كل النصوص تأتي مباشرة من وثيقة الكشف؛ لا نجمع أرقامًا بمكتبة Canvas. Unit يراجع هوية مراجع كل صف والملخص.
- **قابلية القراءة:** Cairo المحلي محمّل قبل الرسم؛ حجم PNG وإحداثيات الأعمدة RTL؛ text maxWidth يضغط النص الطويل وليس حذفًا صامتًا. التحقق من صورة فعلية في Chromium، مع الاحتفاظ بحد طول موثق.
- **حالات الفشل:** لا تنزيل للفترة غير الصالحة؛ الفترة بلا حركات لها عبارة صريحة؛ تحميل خط/Canvas أو toBlob فاشل يظهر رسالة؛ قفل الزر يمنع تكرار الطلب.
- **حدود الأمان:** لا backend/secret أو Supabase أو تخزين مالي؛ route العامة كما كانت، وعدم كشف خارج DemoStore.
- **ما لم يشمله الاختبار:** أجهزة Android حقيقية، صلاحية ملف صورة شديدة الطول، PDF محلي مرقم، Excel، مدفوعات أو صيغ الإنتاج. T09 ليست مكتملة.

## بوابة الدمج
مرور نقدي مستقل بعد قراءة patch وتحديد كل المسارات المتأثرة؛ CI على آخر commit: npm ci/check، SQL معزول وnegative controls، build وHTTP/SDK، Vitest وصورة متصفح PNG حقيقية. سجّل النتائج في تعليق PR بدل تعديل الوثائق بعد نجاح الاختبارات.
