# المهام

الحالة بتاريخ **٥ نوفمبر ٢٠٢٦ / H038**: النظام يضم أربع حزم مستقلة وتطبيق معاينة بالذاكرة، ومراحل SQL A/B/C موجودة في المستودع (٩ migrations أصلية للقاعدة وثلاثة أجنحة A/B/C). **H037 وثّق تشغيل A/B فقط**؛ كود C موجود على main لكنه لم يحصل على دليل تشغيل جديد. H038 أضاف Migration عاشرة واختبارات وصف النقلة على فرع PR #1، ولم تُدمج؛ اجتازت اختبارات SQL في GitHub Actions H038. GitHub repo موجود الآن `body199-cmyk/1-mohamed` (Public؛ يحتاج قرار خصوصية عند إدخال بيانات حساسة). Supabase Auth الحقيقي والحفظ الدائم لم يُنفذا. راجع [STATUS](STATUS.md) و[تقرير H038](DB_03_H038_REVIEW.md).

## قالب بطاقة التنفيذ

تكليفات استكمال التصميم PLAN-01 إلى PLAN-05 وحزم الحسابات والتسجيل وكشف المقاول PACKAGE-01 / ENTRY-01 / REPORT-01 في [SUBTASKS](SUBTASKS.md)، وحالتها هناك. ترتبط بـT01/T02/T04 وتجهيز T05/T06، ولا تُعد تنفيذًا لتلك المراحل الكاملة. توزيع العمل: المساعد يتولى التقنية والتخطيط وتدقيق التغييرات، والمستخدم يعتمد تجربة الاستخدام والقرارات التجارية، وAntigravity أنجز التوثيق في UI-01 إلى UI-04-FIX-03 (وقبل المساعد إصلاحات المعاينة دون ادعاء اعتماد المستخدم للشكل النهائي)، وصحح مواصفات PLAN-02 في PLAN-02-FIX-01، واستخرج حزمة الحسابات المستقلة وتحقق منها في PACKAGE-01-VERIFY وقَبِل المساعد سلوكها الحسابي وفحص الأنواع واختباراتها الـ ٧٣، وأنجز دمج محرك تسجيل النقلات المستقل في ENTRY-01-INTEGRATE (دليل H029 وتقرير ENTRY_01_VERIFICATION) وقَبِل المساعد سلوكها ضمن الذاكرة، وأنجز مهمة ترقية وتدقيق أدوات الحزمتين TOOLS-02 واعتمدها المراجع (دليل H030 وH031)، وأنجز مهمة دمج محرك كشف شغل المقاول REPORT-01-INTEGRATE (دليل H032 وتقرير REPORT_01_VERIFICATION) وحالتها تحتاج مراجعة المساعد. لا يعتبر التطبيق مكتملًا. مراجعة المستخدم لشكل الشاشة تسبق برمجتها.

تفصيل T07/T08/T10 ومعايير اكتمال خطواتها في [SUBTASKS](SUBTASKS.md). [PROMPTS](PROMPTS.md) يوفر قالب تكليف موحدًا يقرأ صف الخطوة دون نسخ قواعد متكررة. المرحلة الأم لا تُنفذ دفعة واحدة.

لكل مهمة بدأ تنفيذها: المعرف — الهدف — الحالة — الملفات الفعلية — خارج النطاق — الاعتماديات والقرار المانع — شروط القبول — خطوات ونتائج التحقق — المتبقي — رابط التسليم. تُقسم المهمة الكبيرة إلى T07.1 وهكذا قبل تغيير عدة مسؤوليات معًا.

لا تطبق خطة ضخمة في تغيير واحد. الترتيب في الجدول يبين الاعتماديات، ولا يمنع تجهيز مواصفات أو اختبارات مستقلة مبكرًا.
