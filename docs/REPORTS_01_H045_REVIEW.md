# H045 / REPORTS-01 — تقرير الشغل اليومي

## نطاق المهمة
- تقرير يوم **واحد** من النقلات الموجودة في DemoStore. فلاتر التاريخ والمقاول والعربية؛ مع الإجمالي والحركات في اتجاهي AHMED_SUPPLIES وOTHER_SUPPLIES بشكل منفصل.
- إعادة استعمال \`calculateTripAmounts\` للتحقق من snapshots و\`summarizeTrips\` للتجميع، دون معادلات يدوية أو أرقام floating-point.
- ملخص وزن/عدد/قيمة شغل المقاول/مستحق العربية **عن النقلات**، والاحتفاظ برقم الإيصال كنص (الأصفار البادئة). تاريخ الشغل فقط وليس تاريخ إدخال الصف.
- سجلات المقاولين والعربيات المؤرشفة مرئية ضمن التاريخ إذا ظهرت في النقلات. عرض يوم خالٍ من دون استخدام رصيد افتتاحي أو دفعات.

## خارج النطاق
- لا تقرير دفعات/رصيد نقدي متبقٍ ولا تجميع افتتاحيات ولا تقرير «المدفوع للمقاول»؛ لا تغيير بيانات النقلة أو إلغائها، لا Supabase/Vercel ولا مصادقة حقيقية ولا تخزين دائم.
- لا تقرير شهري أو PDF/Excel. T08 الكاملة ما زالت تتطلب D15/D16 والمصدر المحمي الحقيقي.

## مراجعة نقدية مستقلة ونقاط فشل يُختبر منعها
- **مبالغ:** محرك \`calculateTripAmounts\` يراجع كل صف مقابل المبلغ المحفوظ، ثم \`summarizeTrips\` يجمع النتائج؛ عند اختلاف أي قيمة أو اتجاه غير معروف تتوقف النتيجة بدل عرض إجمالي كاذب. وحدة قروش وrounding واختبار 0.005 طن، استبعاد المزج بين اتجاهين.
- **هوية/تاريخ:** مقارنة يوم العمل ISO كاملًا (لا timezone shift)، تاريخ غير موجود مثل 2026-02-29 مرفوض، فلتر المقاول/العربية بالمعرف لا الاسم، وأرشفة لا تمحو النقلات القديمة.
- **واجهة:** تمرير جدول بعرض داخلي للموبايل، لا overflow على الصفحة، حالة خالية مفهومة، دعم أسماء عربية، dark/light CSS المتغيرات الموجودة.
- **أمان:** مسار demo عام فقط، لا API أو صلاحيات بيانات حقيقية ولا auth bypass. تحقق HTTP يعترف بمسار التقرير العام فقط ويبقي المسارات الأخرى مغلقة.
- **تحقق نهائي مطلوب قبل الدمج:** GitHub Actions الكامل على *آخر commit* بما فيه Unit & isolated SQL & negative controls & SDK / HTTP & Next build وChromium القديمة والجديدة. تقرير المراجعة والتحقق النهائي يُكتب في PR review دون تعديل ملفات بعد نجاح CI لتجنب لوب.
