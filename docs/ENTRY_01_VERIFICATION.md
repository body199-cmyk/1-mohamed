تم تنفيذ الأوامر من مجلد `packages/trip-entry/`:

- **النتيجة:** نجاح تام (Exit Code 0) وصفر أخطاء نوع، دون استخدام `@ts-ignore` أو تعريفات وهمية.

## 5. التحقق من القواعد السلوكية الدقيقة للتكليف

1. **حماية المسودة الحالية عند تطبيق المشترك:** أثبت الاختبار أن `APPLY_SHARED` يضع لقطة في `appliedShared` دون تعديل أي حقل من حقول `tripDraft` القائمة.
2. **عزل تعديل المشترك عن اللقطة المطبقة:** تعديل `sharedDraft` بعد التطبيق لا يغير `appliedShared` ولا النقلة النشطة.
3. **حفظ النقلة وتصفير المشترك عند بدء الجلسة (`START_NEW_SESSION`):** التاريخ الجديد يعيد المشترك فارغًا ويمسح المطبق، مع بقاء `tripDraft` السابقة غير المحفوظة بكامل بياناتها وتاريخها دون فقد.
4. **بدء النقلة البديلة (`START_NEW_TRIP`):** هو المنفذ الوحيد لاستبدال المسودة بالقيم المشتركة وتصفير حقول النقلة الخاصة (`vehicleId`, `weightTonnes`, `receiptNumber`, `notes`).
5. **تعطيل المشترك (`DISABLE_SHARED`):** يصفر `appliedShared` ولا يمس `tripDraft`.
6. **عدم توريث أو فرض الاتجاه:** الاتجاه يبدأ `null` ويبقى `null` ولا يتحول تلقائيًا إلى `"AHMED_SUPPLIES"`.
7. **رفض تعديل سعر العربية أثناء الربط:** عند `sameRate: true`، يعيد التعديل المباشر `{ ok: false, error: { code: "VEHICLE_RATE_LINKED" } }` ويبقى السعر دون تغيير.
8. **عزل الحسابات والقرارات المالية:** المحرك لا يجري أي عمليات تقريب، ولا يفحص صحة تنسيق الأرقام، ولا يقرر صلاحية الحفظ؛ فالنصوص تُحفظ كما أُدخلت.

## 6. حدود الدمج وما لم يُختبر أو يُربط بعد

1. **ذاكرة فقط (In-Memory State):** هذا المحرك يدير الحالة في الذاكرة أثناء عمل التطبيق فقط؛ لا يحفظ البيانات عند إغلاق المتصفح (`localStorage` أو خادم)، ولا يسجل نقلات في قاعدة بيانات.
2. **تأكيد فقد المسودة مسؤولية الواجهة:** طلب تأكيد المستخدم عند محاولة استبدال مسودة محررة عبر `START_NEW_TRIP` هو مسؤولية طبقة الواجهة (UI Controller / Modal) لاحقًا، وليس من وظائف محرك الحالة المجرد.
3. **عدم الربط بالواجهة أو المعاينات بعد:** لم يتم ربط هذا المحرك بالمعاينة المرئية `daily-work-preview-v2.html` أو أي مكونات React/Next.js حتى الآن.
4. **استقلالية الحزمة:** حزمة `packages/trip-entry` منفصلة تمامًا عن `packages/accounting`؛ لا تعتمد إحداهما على الأخرى برمجياً في هذه المرحلة.
5. **القرارات المفتوحة:** قرارات الدفعات D15 وD16 لم تُمس وظلت مفتوحة لقرار المستخدم دون اعتماد ضمني.
