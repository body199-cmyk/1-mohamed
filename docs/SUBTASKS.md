# وحدات التنفيذ الصغيرة

هذا تفصيل للمهام الأم في [TASKS](TASKS.md)، وليس إذنًا بالتنفيذ. **حالة كل خطوة موضحة ببطاقتها؛ ما لا يحمل دليل تنفيذ يظل لم يبدأ** وترث اعتماديات وقرارات المهمة الأم. تحديث الحالة يتم هنا لكل خطوة، وحالة الأم تُشتق من اكتمال خطواتها والتحقق المتكامل. الملفات الفعلية تُحدد قبل التنفيذ من [CODE_MAP](CODE_MAP.md) بعد D08/T04؛ النطاق أدناه وحدات مقترحة، لا أسماء ملفات مختلقة.

## شرط اكتمال مشترك لكل خطوة

- [ ] حُسمت القرارات المؤثرة وثُبتت المدخلات والمخرجات والملفات الفعلية في بطاقة التنفيذ.
- [ ] اقتصر التغيير على النتيجة المذكورة، دون معادلات أو حقول إضافية غير معتمدة.
- [ ] تحقق القبول الخاص أدناه نجح مع تسجيل الدليل وما لم يُختبر.
- [ ] فُحص فشل واقعي عند وجود حفظ/مال/صلاحيات، وليس المسار الناجح فقط.
- [ ] حُدّثت الحالة والخريطة عند تغيرها وسجل التسليم؛ لا تُعلن الأم مكتملة دون تحقق الربط.

لا حصة ثابتة «اختبارين لكل خطوة»: وثيقة تُراجع، وواجهة بسيطة تُفحص، وحفظ مالي يحتاج اختبارات فعلية للقاعدة ومسارات الفشل. لا نفترض ضمان إتمام الخطوة في جلسة واحدة؛ إذا اتسع النطاق تُجزأ أكثر. لا تُطلق خطوة فرعية وحدها للإنتاج إذا لم يكتمل التكامل الآمن.
