# UI-BASE-01A / H043 — شاشة بيانات المقاولين والعربيات (معاينة محلية)

**التاريخ:** ٥ نوفمبر ٢٠٢٦. [PR #6](https://github.com/body199-cmyk/1-mohamed/pull/6)، الفرع `feat/ui-base01a-master-index-h043`. **حالة الإنشاء:** غير مدموج حتى انتهاء المراجعة والـCI؛ ليست شاشة حفظ دائم.

## ما كان موجودًا قبل التنفيذ

- `apps/web/src/demo/demo-context.tsx` يحتوي بالفعل على `contractors` و`vehicles` و`addContractor` و`addVehicle`. `quick-add-modal.tsx` يتيح إضافة سريعة أثناء إدخال النقلة.
- `/demo/trips` و`/demo/contractors` موجودتان. البيانات تعيش في React in-memory state فقط. يوجد رصيد افتتاحي لفرق شغل المقاول، **وليس افتتاحيًا نقديًا لكل عربية عند مقاول مسؤول**.
- لذلك لم ننشئ مخزنًا جديدًا أو معادلة مالية أخرى، بل أعدنا استخدام نفس Context و`QuickAddModal`.

## ما لم ينفذ (لا ادعاء بالإتمام)

- لا تعديل بيانات موجودة أو أرشفة/إعادة تفعيل، ولا حذف، ولا صلاحيات حقيقية.
- لا واجهة افتتاحي النقدية للعربية **لكل زوج عربية/مقاول مسؤول**. ذلك حساب منفصل عن افتتاحي فرق شغل المقاول، وهو مهم؛ لا يجوز عرض واحد مكان الآخر.
- تكرار اسم المقاول/لوحة العربية محجوب في نافذة المعاينة فقط؛ التحقق النهائي عند الحفظ الإنتاجي مسؤولية DB/RPC.
- لا بيانات دائمة أو Supabase أو Vercel أو دفعات أو API جديد. اختبار HTTP يفحص HTML والروابط، **ولا يمثل E2E تفاعليًا كاملًا**؛ اختبار إضافة/بحث بالمتصفح مطلوب لاحقًا عند اكتمال UI-BASE وتوفر بيئة browser مناسبة.

## التحقق والمراجعة النقدية

- CI المطلوب على **أحدث commit**: `npm ci`، `npm run check` (١٦٧ اختبار وحدة)، `npm run db:verify` (١٦ خطوة SQL)، ٣ negative controls، Next build، H041 SDK inactivity، H039 HTTP smoke المحدث. لا اعتماد بلا logs حقيقية.
- مرور نقدي منفصل يشمل: تكرار اللوحات رغم اختلاف الأرقام العربية، عدم تكرار المحرك المحاسبي، عرض فرق الشغل **مقابل** النقد، عدم كشف route دائم، RTL والموبايل، فراغ البحث وعودة قائمة المقاولين.
- **نقطة الاستئناف بعد قبول UI-BASE-01A:** `UI-BASE-01B` — تحرير البيانات الأساسية مع تاريخ وأثر/سبب مناسب، أرشفة آمنة دون حذف التاريخ، وواجهة حساب العربية النقدي والافتتاحي حسب المقاول المسؤول؛ مراجعة `D04` قبل أي تحويل تاريخي. الحفاظ على بيانات demo مؤقتة حتى ربط Supabase النهائي.
