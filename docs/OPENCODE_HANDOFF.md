### ملحق الجلسة — حالة المصادقة (آخر فحص بالجلسة)

- فحص المحلية: `.git-credentials` موجود **بلا** سطر `github.com`؛ credential.helper = store؛ لا `gh` CLI منصب؛ SSH (git@github.com على 22 وssh.github.com على 443) محجوب من الشبكة، بينما HTTPS للقراءة شغال (استرجاع وfetch وls-remote نجحوا).
- **التالي بالإذن:** تسجيل دخول GitHub مرة واحدة من الجهاز — بإحدى طريقتين المملوكتين للملاك: (أ) تنفيذ `git push -u origin opencode/local-work` في طرفية تفاعلية حيث تظهر نافذة تسجيل الدخول وتُخزَّن بصمة الاعتماد محليًا، أو (ب) تنصيب `gh` وتسجيل الدخول عبر `gh auth login`. **لا يُطلب أي token في أي شات إطلاقًا** (بروتوكول §2).
- بعد توفر المصادقة: التحقق من SHA الوجهة عبر `git ls-remote origin opencode/local-work` وتسجيله في أول سجل بالأعلى.
