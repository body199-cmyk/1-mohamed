# تصدير كشف المقاول

حزمة نقية تحول `ContractorStatementDocument` (نصوص جاهزة) إلى HTML عربي RTL أو CSV، دون حساب أو وصول لبيانات. نصوص HTML تُهرب، وخلايا CSV تُحمى من بدء صيغة جدول. المبالغ المنسقة نصوص وليست خلايا أرقام قابلة للجمع تلقائيًا.

التشغيل من جذر المشروع: `npm ci` ثم `npm run check`. اختبار الحزمة وحدها: `npm run check --workspace=@ledger/statement-export`.

الخط المحلي وفتح نافذة الطباعة وتنزيل الملف مسؤولية تطبيق الويب. الحزمة لا توفر PNG أو XLSX أو محرك PDF؛ المتصفح يقدم الحفظ PDF من الطباعة. المصدر الأول: ملف `export_01_delivery.md` الذي أرسله المستخدم؛ دُمجت ملفات المصدر والاختبارات الثمانية.
