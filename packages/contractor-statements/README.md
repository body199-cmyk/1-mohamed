# REPORT-01 — محرك كشف فرق الشغل بين أحمد ومقاول آخر خلال فترة

حزمة TypeScript مستقلة لحساب كشف فرق الشغل (بالقروش `bigint`) بين أحمد ومقاول آخر خلال فترة زمنية محددة، دون اعتماد على قاعدة بيانات أو واجهة أو تصدير PDF أو قواعد دفعات نقدية.

## هيكل الحزمة

- `src/statement-types.ts`: عقود الأنواع للمدخلات والمخرجات وأكواد الأخطاء.
- `src/statement-validation.ts`: التحقق الصارم من التواريخ (`YYYY-MM-DD` مع السنوات الكبيسة والنطاق `0001–9999`) والمبالغ النصية والمعرفات وترتيب أولويات الأخطاء.
- `src/contractor-statement.ts`: الدالة الرئيسية `buildContractorStatement` لحساب رصيد أول الفترة، إجماليات شغل أحمد والطرف الآخر، الرصيد التراكمي لكل حركة، والرصيد الختامي والطرف المستفيد.
- `src/index.ts`: نقطة التصدير الموحدة للحزمة.
- `tests/test-helpers.ts`: كائن أساسي للمدخلات المشتركة لخدمة الاختبارات.
- `tests/validation-dates.test.ts`: اختبارات التحقق من التواريخ والسنوات الكبيسة وحدود الفترات.
- `tests/validation-amounts.test.ts`: اختبارات التحقق من مبالغ الافتتاحي والنقلات وتطبيع الأصفار.
- `tests/validation-accounts-and-ids.test.ts`: اختبارات معرفات الحساب وتطابقها ومنع المعرفات المكررة.
- `tests/validation-error-priority.test.ts`: اختبارات الترتيب الحتمي لأولوية الأخطاء في الترويسة والحركات.
- `tests/statement-calculation.test.ts`: اختبارات سيناريو القبول الرئيسي والأرصدة والأعداد الكبيرة.
- `tests/statement-periods-and-ordering.test.ts`: اختبارات حدود الفترة، الفرز الحتمي، جمود المدخلات، وقابلية التسلسل JSON.

## حدود الاستخدام والمسؤوليات المعمارية الضرورية

1. **اشتراط لقطة مكتملة (Complete Snapshot Required):**
   - هذه الوحدة تحتاج لقطة مكتملة من كافة الحركات الفعالة للحساب من تاريخ الافتتاحي (`opening.startDate`) حتى نهاية الفترة المطلوبة (`period.to`).
   - **لا يجوز إطلاقًا** تمرير صفحة واحدة من نتائج قاعدة البيانات (Pagination) واعتبارها كشفًا كاملًا؛ فالرصيد الافتتاحي للفترة يُحسب بتراكم حركات ما قبل الفترة مع الرصيد الافتتاحي.
2. **مسؤولية طبقة البيانات (Data Layer Responsibility):**
   - طبقة البيانات مسؤولة حصرًا عن ضمان اكتمال اللقطة، استبعاد الحركات الملغاة، واختيار أحدث النسخ المصححة للنقلات؛ هذا المحرك النقي لا يتصل بقاعدة بيانات ولا يستطيع اكتشاف حركات حُذفت أو لم تُرسل إليه في المدخلات.
3. **ترتيب حركات اليوم نفسه:**
   - فرز الحركات داخل نفس اليوم حسب المعرف (`id`) هو لأغراض العرض الحتمي فقط (`deterministic presentation sorting`)، وليس ترتيبًا زمنيًا حقيقيًا لحركات اليوم.
4. **تصدير مسارات TypeScript:**
   - تصدير مسارات TypeScript من ملفات المصدر (`exports: { ".": "./src/index.ts" }`) لا يعني وجود حزمة JavaScript مبنية ومجمعة للتشغيل المباشر بواسطة Node دون معالجة أو بناء.
5. **حدود النطاق:**
   - الحزمة لا تدّعي تنفيذ أو دعم قاعدة بيانات، أو تصدير PDF/Excel، أو مصادقة وصلاحيات مستخدمين، ولا تتعامل مع الدفعات النقدية؛ نطاقها محصور في الحساب النقي لكشف فرق الشغل.
