# حزمة الحسابات المالية المستقلة للنقل (`transport-accounting-calc-package`)

حزمة حسابية وتنسيقية مستقلة (Pure TypeScript / `bigint`) لحساب قيم النقلات وتجميعها وتنسيق المبالغ بالجنيه المصري دون استخدام الفاصلة العائمة (`Number` / `parseFloat`).

## 1. وظيفة كل وحدة وحدود مسؤوليتها

| الوحدة | الدالة المصدّرة | ما تفعله | ما لا تفعله |
| :--- | :--- | :--- | :--- |
| `src/trip-amounts.ts` | `calculateTripAmounts` | تتحقق من صيغة ودقة مدخلات النقلة الواحدة، وتحسب قيمة المقاول ومستحق العربية بالقروش (`string`) بشكل مستقل مع إضافة المصاريف مرة واحدة لكل منهما. | لا تجمع القيمتين في إجمالي واحد، لا تحول الأرقام العربية أو تنسق مدخلات الواجهة، ولا تقرر صلاحية حفظ نقلة وزنها صفر تجاريًا. |
| `src/trip-summary.ts` | `summarizeTrips` | تستقبل قائمة نقلات وتتحقق منها بالترتيب عبر `calculateTripAmounts`، وتجمع الأوزان (بثلاث منازل عشرية) وإجماليات القروش المقربة لكل نقلة، وتتوقف عند أول خطأ مع إرجاع فهرسه (`index`). | لا تصفي النقلات حسب التاريخ أو المقاول، لا تدمج النقلات المتشابهة، لا تعيد إجماليات جزئية عند الفشل، ولا تحسب دفعات أو أرصدة افتتاحية أو أرباحًا. |
| `src/format-egp.ts` | `formatEgpFromPiastres` | تحول نص عدد صحيح من القروش (موجب أو سالب أو صفر) إلى نص مبلغ بالجنيه المصري بمنزلتين عشريتين دائمًا مع `currencyCode: "EGP"` وتطبيع الصفر السالب إلى `"0.00"`. | لا تقبل الكسور أو علامة `+` أو المسافات أو الفواصل، لا تغير قيمة المبلغ، ولا تحدد اتجاه المديونية (من له أو عليه المال). |

## 2. تمثيل المال والوزن وقواعد الدقة والتقريب

* **المال نص بالقروش، والوزن نص بالطن:**
  * تُسلّم المبالغ الناتجة من الحساب والتجميع كنصوص أعداد صحيحة بالقروش (`Piastres`)، ويُسلّم إجمالي الأوزان كنص بالطن بثلاث منازل عشرية ثابتة (`"0.000"`).
  * جميع العمليات الحسابية تتم داخليًا باستخدام `bigint` (الوزن بوحدة الكيلوجرام = $10^{-3}$ طن، والمال بالقرش = $10^{-2}$ جنيه)، مما يحافظ على الدقة الكاملة حتى للأعداد التي تتجاوز `Number.MAX_SAFE_INTEGER`.
* **التقريب لكل نقلة قبل التجميع:**
  * يُقرب حاصل ضرب (الوزن × السعر) في كل نقلة إلى أقرب قرش (نصف القرش لأعلى) مرة واحدة فقط داخل `calculateTripAmounts`.
  * تجمع `summarizeTrips` القيم المقربة الناتجة من كل نقلة مباشرةً، ولا تجمع القيم الخام قبل التقريب.
* **التنسيق لا يغير القيمة:**
  * دالة `formatEgpFromPiastres` تفصل القروش إلى جنيهات وقروش نصيًا/حسابيًا عبر `bigint` دون أي تقريب أو تعديل للقيمة المالية.
